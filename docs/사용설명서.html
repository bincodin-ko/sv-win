Symvibe Windows판 사용 설명서

여러 AI 코딩 에이전트(Claude Code·Codex 등)를 한 보드에 띄워 놓고 한꺼번에 지휘하는 데스크톱 앱입니다. 개인용이라 로그인·구독이 없습니다.

키는 소스 코드(appKeys.ts·keys.ts·fixedKeys.ts·keymap.ts) 기준입니다.

1. 처음 쓰기

  1. 첫 실행 3단계. 처음 켜면 안내 카드가 뜹니다: 1) 테마 고르기 → 2) repo(폴더) 추가 → 3) 에이전트 고르기. 마지막 Start를 누르면 처음 추가한 repo의 보드가 열리고 고른 에이전트 1개가 자동으로 뜹니다. 오른쪽 위 ×로 건너뛸 수 있습니다.
  2. repo 열기. 홈 화면에서 폴더를 고르거나 Ctrl+O. 최근 repo는 목록에 남고 클릭 한 번으로 열립니다.
  3. 에이전트 띄우기. 보드에서 T(Spawn agent) 또는 빈 보드의 Spawn 단추. 설정 › Agents에서 기본 에이전트를 정합니다. 각 에이전트는 보드 위 "콘솔" 창으로 뜹니다.
  4. 명령줄로 지시. 화면 아래 명령줄(Ctrl+K)에 한국어로 씁니다. 예: 클로드 두 개 띄워 → @Otto 테스트 돌려 → 전부 멈춰.
  5. 그룹 묶기. 콘솔 2개 이상을 고르고 Ctrl+G(해체 Ctrl+Shift+G). 또는 클로드 세 개로 그룹 만들어. 이후 그룹 1에 테스트 돌려처럼 한 번에 지시합니다.
  6. 저장·다시 열기. 보드는 자동 저장됩니다(Ctrl+S를 누르면 바로 저장하고 "Saved" 알림이 뜹니다). repo를 닫았다 다시 열면 같은 보드가 돌아오고, 끝난 에이전트 대화는 Resume으로 이어받습니다. 설정 › General의 "Reopen last repo on launch"를 켜면 시작할 때 마지막 repo가 열립니다.

3. 기능별 설명

  • 보드 — 끝없이 넓은 캔버스. 콘솔·메모·도형·펜 그림·이미지를 놓고 끌고 확대합니다. 우클릭 메뉴와 좌우 레일에 도구가 있습니다.
  • 콘솔 — 에이전트가 도는 터미널 창. 상태가 STARTING / WORKING / NEEDS YOU / DONE / ERROR 등으로 표시되고, 끝난 대화는 Resume으로 이어갑니다.
  • 명령줄 — 한국어·영어 모두 됩니다. 예문:
    클로드 두 개 띄워 코덱스 세 개 만들어 @Otto 테스트 돌려 Otto한테 테스트 돌려라고 해 모두에게 린트 돌려 Otto 멈춰 다시 진행해 Otto 닫아 상태 누가 끝났어? 전체 보기 확대 Otto로 가 설정 열어 메모리 열어 10분마다 테스트 돌려 도움말
    못 알아들으면 안내 문구가 나옵니다(PC 안 내장 해석기만 사용). 받는 이름을 먼저(@Otto …) 쓰면 가장 정확합니다.
  • 그룹 — 콘솔 묶음. 그룹 단위로 지시·멈춤·재개·닫기. 그룹 1에 클로드 하나 추가해처럼 늘릴 수 있습니다.
  • Presets — 미리 만들어 둔 에이전트 배치를 보드에 한 번에 펼칩니다. 프리셋 열어.
  • Git — G 패널과 보드의 pill·브랜치 카드. 명령줄에서 commit and push, pull(영어 문형)도 됩니다.
  • 노트 / 칸반 — 메모, 체크리스트, 캘린더, 칸반을 보드에 놓습니다. add a note that says ship it, add a kanban.
  • 스튜디오 — Code · Markdown(D) · Documents(PDF 내보내기는 Edge 인쇄 방식이라 목차에 쪽 번호 없음) · Diagrams. 코드 열어, 마크다운 열어, 문서 열어.
  • Loops — 일정 간격으로 같은 지시를 반복(예: 10분마다 테스트 돌려). 앱을 켜면 모든 loop는 꺼진 채로 불러오니, 필요하면 다시 켜세요.
  • Memory — repo에 대한 사실을 모아 두고 에이전트에게 전달하는 패널(M). Scan은 Claude Code·Codex만 지원합니다.
  • Mission Map — 그룹·콘솔·오케스트레이터 연결을 한 장 지도로 봅니다(미션맵 열어).
  • Usage — 토큰 사용량·한도 pill·히트맵(로컬 로그 기준, Claude·Codex만). 사용량 열어.
  • 프로필 — 에이전트별 설정 폴더를 분리해 계정을 나눠 씁니다. 로그인 파일은 복사하지 않으니 프로필마다 처음 한 번 에이전트 안에서 직접 로그인하세요.
  • 음성 — Space 길게 = 말로 명령, 받아쓰기 키(기본 Ctrl+Space) 길게 = 받아쓰기(whisper.cpp, 처음 한 번 모델 내려받기, 소리는 PC 밖으로 안 나감). 답 읽어 주기는 PC 로컬 음성(영어)입니다.

5. 자주 묻는 것

  • 명령을 못 알아들어요. "도움말"을 입력하면 되는 문형이 나옵니다. 받는 이름을 먼저(@Otto …) 쓰세요. 영어와 한국어만 지원합니다.
  • 콘솔 안에서 단축키가 안 먹어요. 콘솔 안에서는 Claude Code 같은 프로그램이 키를 가집니다. 앱 키(F6, Ctrl+F6, Ctrl+Shift+P 등)는 콘솔 안에서도 먹지만 Ctrl+O는 양보합니다. 보드 빈 곳을 한 번 클릭한 뒤 쓰세요.
  • 받아쓰기가 안 돼요. 처음 한 번 모델을 내려받아야 합니다(설정 › Voice). 기본 Ctrl+Space가 안 되면 설정 › Voice에서 다른 키를 고르세요. 일부 한국어 키보드에서는 Right Ctrl/Alt가 한자·한/영 키라 안 먹을 수 있으니 Right Shift를 써 보세요.
  • 보드가 저장됐는지 모르겠어요. 자동 저장이며, 종료할 때 실행 중인 에이전트가 있으면 확인창이 먼저 나옵니다.
  • 앱을 끄면 에이전트는요? 앱이 꺼지면 자식 프로세스도 함께 꺼집니다(Windows Job Object). 다시 열면 Resume으로 이어받을 수 있습니다.

6. 데이터 위치·제거

  • 저장 위치: %APPDATA%\com.symvibe.win (보드·설정·repo 목록). 이 PC에서만 쓰고 서버가 없습니다.
  • 제거: 설정 → 앱 → Symvibe → 제거.
  • 설정·보드까지 지우려면 제거 뒤 위 폴더를 직접 삭제하세요. 백업하려면 폴더를 통째로 복사해 두면 됩니다.
